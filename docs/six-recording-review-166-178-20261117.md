## Changes deployed

- Recognize direct “forwarded to voicemail”, including clipped STT wording; carrier spam-block announcements; and press-one connection challenges. Also recognize the exact fragmented screening sequence with nearby user turns. Never hang up merely for “Thank you for calling”, a digit, unavailability, human questions or reported/quoted voicemail.
- Apply detection in both shared engine and bridge user/probe paths. Stop queued/late speech, emit no machine reply and close locally without waiting for a slow persistence callback. Ended voicemail sessions remain terminal.
- Ignore empty PCM heartbeats as audio, allowing captured speech to finalize when actual input stops. Metadata/link retries no longer freeze the conversation silence clock; explicit transfer/handoff states remain protected.
- Presence questions have a call-wide budget across intervening speech. Early final goodbye starts only the final hangup window; real speech can still cancel that window. No-response close does not depend on backend callback completion.
- Skip empty acknowledgment sentences when resuming the last meaningful point. Suppress guessed-meaning statements and unsupported stock positive wellbeing acknowledgments before model output reaches transcript or TTS. Add explicit grounding rules for incomplete/foreign-language fragments, uncertainty and wrong-person replies. These are targeted safeguards; they do not make all speech recognition reliable or guarantee customer retention.
