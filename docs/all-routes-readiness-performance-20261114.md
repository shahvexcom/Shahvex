Performance corrections:
- Authenticated non-mutating speech probes now read connection/call identity and current call/transfer status, then use the existing session without mutation-ledger or transcript writes. Authorization, signature and call-identity checks remain. This removes multiple cloud database round trips from early interruption recognition.
- Transcript progress writes no longer await in the audio read loop. At most one coalesced progress write is in flight, and final persistence waits for it to finish before final state. Slow database writes cannot hold back subsequent audio packets.
- Global speaking pace is 1.10 through streamed ffmpeg atempo processing for approved local 24 kHz PCM speech. Pitch, voice selection, sample rate, model precision and emotion settings are retained. SHAHVEX_SPEECH_TEMPO=1 disables this adjustment; the supported ceiling is 1.2. Streaming cancellation closes the processor and cancels upstream audio. No model/voice-engine restart was required.

Cloud database measurements were 164–168 ms per warm query and 1218 ms including initial connection, explaining the cost of repeated synchronous metadata writes. A live speech-probe benchmark was skipped because the active call had ended; no fake customer call was created to obtain a number. No full-concurrency load benchmark is claimed.
